HTML Formatter & Minifier

Format or remove whitespace between recognized block-level HTML elements without rewriting attributes or inline text.

How HTML Formatter & Minifier Works

This tool formats or removes whitespace-only gaps between recognized block-level HTML elements. It does not rewrite HTML attributes or ordinary text content.

How to Format HTML

Paste your HTML source code and select Format HTML. The tool inserts line breaks between adjacent recognized block-level elements to improve source readability.

How to Minify HTML

Select Minify HTML to remove unnecessary whitespace-only gaps between recognized block-level elements. Other whitespace and text content remain unchanged.

Example

Adjacent div, section and paragraph elements can receive line breaks. Spaces between inline span elements remain unchanged.

Protected HTML Content

Content inside script, style, pre, textarea, title and other protected elements is preserved. Comments and attribute values are also retained.

Limitations

This is a conservative whitespace formatter, not a complete HTML parser, validator or sanitizer. It does not automatically indent nested elements, remove comments, optimize attributes or repair malformed HTML. Always inspect the result before publishing.

Privacy

HTML processing takes place locally in your browser. Your source code is not sent to an external formatting API.

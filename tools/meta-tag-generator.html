Meta Tag Generator

Create SEO optimized meta tags for your website.

How Meta Tag Generator Works

Create a copy-ready HTML metadata snippet for your website. The generated code is intended for the head section of your HTML page.

How to use the generator

  1. Enter a unique and descriptive page title.
  2. Write a useful description that accurately summarizes the page.
  3. Enter the canonical URL when the page has a preferred public URL.
  4. Add Open Graph and social sharing image URLs if available.
  5. Choose the appropriate robots directive.
  6. Generate, review, copy or download the resulting HTML.

Understanding the generated tags

  • Title: Defines the document title.
  • Description: Provides a summary that may be used in search snippets.
  • Canonical: Identifies the preferred URL for a page.
  • Robots: Specifies supported indexing and crawling directives.
  • Open Graph: Provides metadata for social sharing previews.
  • Twitter Card: Defines the appearance of supported social cards.

Title and description length

Approximately 50–60 characters for titles and 150–160 characters for descriptions are common editorial guidelines. Search engines may truncate or rewrite displayed titles and descriptions depending on the device, query and available display space.

Important SEO limitations

The keywords meta tag is not used by Google as a ranking signal. A canonical tag is a signal rather than a guaranteed indexing decision. A noindex directive must be accessible to crawlers to be processed. This generator does not submit pages or guarantee indexing or rankings.

Where your data goes

The entered metadata is processed in your browser. This generator does not send your metadata to a remote generation API. The page and its scripts are served by this website.

CSS Formatter and Minifier

Beautify and compress CSS code online.

How CSS Formatter and Minifier works

Reformat CSS spacing while protecting quoted strings, comments, escapes and parenthesized expressions.

Steps

Paste CSS, choose format or minify, and compare the result in your stylesheet before publishing.

Example to check

The value calc(100% - 2px) and a quoted content string retain their internal spaces. A descendant selector such as 'a :hover' retains its meaning.

Limits and review

This lightweight tool does not validate CSS or replace a standards-aware production optimizer. It preserves comments and does not resolve imports, variables or browser compatibility.

Where your data goes

Your selected files and entered content are processed in your browser. Processing does not upload them to a conversion, QR or AI API. The site serves the scripts, fonts and any OCR models needed for the task.

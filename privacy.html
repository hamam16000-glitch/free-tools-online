Privacy Policy

How Free Tools Online handles browser-processed information, cookies and advertising.

Updated November 19, 2026

Processing text and files

The current tools process entered text and selected files in your browser. Conversion, QR generation and OCR do not submit their input to an external conversion, QR or AI API. This site does not provide server storage for your input files. Local processing does not protect against browser extensions, shared-device access or clipboard history.

Hosting and technical requests

GitHub Pages serves pages, scripts, fonts and OCR worker/language files. Loading those assets sends normal web requests, which can include an IP address and browser information. See the GitHub General Privacy Statement. Processing may use browser memory, temporary object URLs, workers and the normal browser asset cache.

Chosen external requests

The YouTube thumbnail tool requests thumbnail images from YouTube. Those requests disclose connection information and the requested video identifier to that service. Following a reference link or sending an email uses the selected external service and its own privacy practices.

Storage, downloads and sharing

The selected theme can be stored in browser local storage. You can remove it in browser site-data settings. Copy actions place the selected output on your clipboard. Downloads save output where your browser directs them. Review generated or converted content before sharing it, and keep the original file until the output has been checked.

Advertising in this release

This release loads no advertising network script and requests no ads. The AdSense verification meta tag identifies the publisher account but does not request advertising. The former Monetag loader is removed. Before ads are enabled, the active providers, their data practices and applicable consent arrangements must be reflected in this policy.
